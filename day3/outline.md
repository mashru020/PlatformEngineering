Day 3: AWS networking and IAM
Study:
- VPC, public and private subnets.
- Internet Gateway and NAT Gateway.
- Route tables and security groups.
- Network ACLs.
- IAM users, roles, policies, and trust relationships.
- AWS STS and temporary credentials.
- VPC endpoints and private access to AWS services.
- Secrets Manager and Systems Manager Parameter Store.
Practical exercise:
Design a VPC with:
- Public subnets for internet-facing load balancers.
- Private subnets for application workloads.
- Isolated or appropriately restricted database subnets.
- Least-privilege IAM roles.
- Restricted inbound and outbound network access.

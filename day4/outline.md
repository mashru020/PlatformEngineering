Day 4: AWS compute, storage, and databases
Study the services explicitly mentioned in the circular:
- EC2: compute, security, scaling, and instance lifecycle.
- EKS: managed Kubernetes control plane and worker capacity.
- RDS: managed relational databases, backups, and Multi-AZ deployments.
- S3: object storage, encryption, versioning, and access control.
Also understand:
- Application Load Balancer.
- Auto Scaling Groups.
- CloudWatch metrics, logs, and alarms.
- Route 53 and DNS fundamentals.
- AWS KMS and encryption.
Practical exercise:
Draw an AWS architecture for a web application deployed in private subnets behind an Application Load Balancer, with an RDS database and S3 storage.
